# Banking System

## Description
A Python-based Banking Management System developed using Object-Oriented Programming (OOP).

## Features
- Account creation
- Savings Account
- Current Account
- Deposit money
- Withdraw money
- Check balance
- Display account details
- Transaction history

## OOP Concepts Used
- Classes and Objects
- Constructor
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Abstract Classes

## Technologies Used
- Python
- Object-Oriented Programming
